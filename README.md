## ⚡ From machines to software

I didn't start my career behind a desk.

My professional background is in **technical service engineering**, where troubleshooting means understanding complex systems, analyzing their behavior and finding the actual root cause instead of simply treating the symptoms.

Today, I apply the same mindset to software development.

```text
Complex problem
      │
      ▼
Understand the system
      │
      ▼
Break it down
      │
      ▼
Find the root cause
      │
      ▼
Build the solution
      │
      ▼
Test → Improve → Ship
```

That journey from machines to software shaped the way I develop:

**structured thinking · curiosity · persistence · practical solutions**

```python

    understand()
    build()
```
